# ToDoリンク

タブで分けるToDoリスト＋Googleカレンダー連携。
森下さん専用（クローズド運用）。サーバー不要・アカウント不要、データは端末のブラウザに保存されます。

保存場所: `I:\_____Claude\apps\todolink\`

**新しく足したもの（これがやりたかったこと）**

- 日時を入れたToDoは**その場でGoogleカレンダーへ自動登録**（繰り返しはRRULEでそのまま反映）。入力欄の右に「📅 ◯◯に追加されます」と出るので、入る／入らないが常に見えます
- 完了したらカレンダーの予定も消す（ON/OFF）
- 逆方向：カレンダーの予定を「📅 カレンダー」タブにToDoとして取り込み
- 同期先カレンダーを選べる（仕事用／プライベート用など）
- `.ics` 書き出し（連携を使わず手動インポートしたいとき用）
- JSONで丸ごとバックアップ／復元
- **各ToDoの右側にカレンダーボタン**（v1.6.0）
  - 灰色の📅＋ … まだ入っていない。押すとカレンダーに追加
  - 青い📅✓ … 登録済み。押すと確認のうえカレンダーから外す（ToDoは残る）
  - 日時が入っていないToDoで押すと、その場で日付・時間を聞いてから登録します
  - 未接続のときは設定画面が開きます
- **📅 カレンダータブ**（タブ列の中で枠線だけの見た目。他のタブと区別してあります）
  - Googleカレンダーの予定が日付ごとに並びます。読むだけの画面なのでチェックボックスはありません
  - 複数カレンダー（個人・会社・祝日など）をまとめて表示。左の色がカレンダーの色です
  - 表示期間は 今日 / 1週間 / 2週間 / 1ヶ月 / 3ヶ月 から選択
  - 予定をタップ → 「ToDoに入れる」または「カレンダーで開く」
  - 自分がこのアプリから送った予定には「ToDo発」と付きます

## 4. Googleカレンダー連携の設定（初回だけ・10分）

### 4-1. Google Cloud でクライアントIDを作る

1. https://console.cloud.google.com/ を開く（普段使っているGoogleアカウントで）
2. 上部のプロジェクト選択 → **新しいプロジェクト** → 名前は `todolink` など → 作成
3. 左メニュー **APIとサービス → ライブラリ** → `Google Calendar API` を検索 → **有効にする**
4. 左メニュー **APIとサービス → OAuth同意画面**
   - User Type: **外部** → 作成
   - アプリ名: `ToDoリンク` / ユーザーサポートメール・デベロッパー連絡先: 自分のGmail
   - スコープ: そのまま次へ
   - **テストユーザー** に自分のGmailアドレスを追加 → 保存
   - ※ 公開申請は不要です。「テスト」のままで自分のアカウントだけ使えます
5. 左メニュー **APIとサービス → 認証情報 → 認証情報を作成 → OAuth クライアント ID**
   - アプリケーションの種類: **ウェブ アプリケーション**
   - **承認済みの JavaScript 生成元** に、使うURLを全部追加：
     - `http://localhost:8931` （PCで動かす用）
     - `https://morishita8268-blip.github.io` （**パスは付けない**。`/todolink/` は書かない）
   - 作成 → 表示される **クライアントID**（`....apps.googleusercontent.com`）をコピー

### 4-2. 使うGoogleアカウント

このアプリで使うのは **morishitaseishin@gmail.com** です（設定 → Googleカレンダー連携 → 使うGoogleアカウント に入っています）。
4-1のOAuth同意画面の「テストユーザー」にも、このアドレスを入れてください。
別のアカウントでログインしてしまった場合は、接続時に警告が出ます。

### 4-3. アプリに登録する

1. アプリ右上の ⚙️ → **Googleカレンダー連携 → 接続設定（クライアントID）** を開く
2. コピーしたクライアントIDを貼って **保存**
3. **接続する** を押す → Googleのログイン画面 → 許可
   - 「このアプリは確認されていません」と出たら **詳細 → 安全でないページに移動**（自作アプリなので正常です）
4. **同期先カレンダー** を選ぶ
5. 完了。以降は**自動で同期し続けます**（下記）

### 4-4. 設定の意味

| 設定 | 動き |
|---|---|
| 期限つきToDoを自動でカレンダーに送る | 期限を入れた瞬間にカレンダーへ予定を作成。オフにすると、ToDo編集画面のチェックを入れたものだけ送る |
| 完了したらカレンダーの予定も消す | チェックした時点で予定を削除。オフなら予定名に ✅ が付くだけ |
| 取り込み範囲 | カレンダーの予定を自動でToDo化する範囲。0でも📅カレンダータブには予定が出ます（見るだけ）|
| 使うGoogleアカウント | 接続時に想定と違うアカウントでログインすると警告が出ます |

## 5. 同期のタイミング（v1.5.0〜）

接続したあとは、こちらが何もしなくても同期し続けます。

| きっかけ | 動き |
|---|---|
| アプリを開いた瞬間 | すぐ同期 |
| 開いている間 | **3分おき**に自動同期 |
| 他のアプリから戻ってきたとき | すぐ同期（前回から45秒以上あいていれば） |
| 圏外から復帰したとき | すぐ同期 |
| 日時つきToDoを追加・編集したとき | その場でカレンダーへ送信 |
| 左上の状態表示をタップ | その場で同期 |

**左上に状態がいつも出ています。**

- 🟢 `同期済み` / `3分前に同期` — 正常
- 🔵 `同期中…` — 通信中
- 🔴 `同期できません` — 失敗（タップで再試行）
- ⚪ `カレンダー未接続` — タップすると設定が開きます

アプリを閉じている間は同期しません（Webアプリの制約）。ただし予定はGoogleカレンダー側に入っているので、**通知はアプリを閉じていても鳴ります**。

---

## 6. 通知について（重要）

- **本命はGoogleカレンダー側の通知**です。予定として登録されるので、スマホのGoogleカレンダーアプリが普通に通知を出します。ここが元アプリより強い部分です。
- アプリ内の「ブラウザ通知」は、**アプリを開いている間だけ**動きます。Webアプリは閉じている間に自力で通知を出せないためです。
- 期限なしのToDoには通知は出ません（カレンダーに送る先がないため）。

---

## 7. データの扱い

- ToDo・タブ・設定はすべて **その端末のブラウザ内（localStorage）** に保存されます。サーバーには何も送りません。
- 端末をまたぐ共有は「Googleカレンダー」経由、または 設定 → データ → **書き出し(JSON)／読み込み** で行います。
- Googleのアクセストークンも端末内に保存されます（有効期限は約1時間、切れたら再接続）。
- 機種変更やブラウザのデータ削除で消えるので、**たまにJSONを書き出して保管庫に置く**のを推奨します。
- パスコードロックは廃止しました（v1.4.0）。締め出される事故が起きたのと、そもそもブラウザのデータを消せば回避できる程度のものだったためです。
  端末を人に見せたくない場合は、iPhone本体のロックで守ってください。
- オフライン用のキャッシュ（サービスワーカー）も廃止しました。古いコードを掴んだままアプリが起動しなくなる事故の原因になったためです。

## 9. うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「接続する」で何も起きない | クライアントIDの **承認済みJavaScript生成元** に `https://morishita8268-blip.github.io` が入っているか確認（パスなし） |
| `redirect_uri_mismatch` / `origin_mismatch` | 同上。`http` と `https`、末尾スラッシュの有無も一致させる |
| `access_denied` | OAuth同意画面の **テストユーザー** に自分のGmailを追加したか確認 |
| 同期はできるが通知が来ない | スマホのGoogleカレンダーアプリ側の通知設定を確認 |
| 更新したのに古い画面が出る | ホーム画面アプリを一度閉じて開き直す。それでもダメなら index.html の `?v=` 番号を上げてpush |
| データが消えた | 設定 → データ → 読み込み で、書き出しておいたJSONを復元 |
